## 🌟 About This Repository

Welcome to my **Power BI Visualization Gallery** — a collection of hands-on practice, visualization experiments, dashboards, and data analysis projects created while learning and working with **Microsoft Power BI**.

This repository covers a wide range of Power BI concepts, from creating individual charts and exploring datasets to building dashboards and performing geographic and time-based analysis.

The main goal of this work was to understand how raw datasets can be transformed into **interactive visualizations, analytical reports, dashboards, and meaningful insights**.

> **Turning raw data into interactive visual insights.**

# 📈 Visualization Practice

The main visualization workbook contains **14–15 sheets covering a wide range of plots and graphs**.

This provided an opportunity to practice different visualization techniques and understand how different chart types communicate different kinds of information.

Some of the visualization areas explored include:

### 📊 Comparison Visualizations

Used to compare values across categories, groups, and different dimensions.

### 📈 Trend Visualizations

Used to understand changes and patterns across time and other ordered dimensions.

### 🔵 Relationship Visualizations

Used to explore relationships between numerical variables and identify possible patterns or correlations.

### 🟨 Distribution Visualizations

Used to understand how values are distributed across different categories and datasets.

### 🗂️ Categorical Visualizations

Used to compare and analyze categorical data through different visual representations.

### 📋 Tables & Analytical Views

Used to examine underlying values and support more detailed data exploration.

> The `01_all_basic_plots` project brings many of these visualization techniques together across multiple Power BI sheets.
